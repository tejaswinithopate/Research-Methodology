# FaultSense AI — Research Prototype
Topic: Semi-Supervised Machine Learning for Industrial Fault Classification with Limited Labeled Telemetry.

## Features
- Account signup/signin with SQLite and password hashing
- Dashboard and saved training runs
- Upload/preview CSV dataset (target column must be `fault_label`)
- Numeric preprocessing and median imputation
- Train/test split; configurable labeled ratio (10% default) on training split only
- Pseudo-labeling via scikit-learn SelfTrainingClassifier
- Compare labeled-only supervised baseline vs semi-supervised model
- Accuracy, precision, recall, F1 and confusion matrix
- Demo prediction page
- Included synthetic demo CSV: 400 rows, 4 illustrative classes

## Important
This project implements pseudo-labeling/self-training. It does NOT implement the Ladder Network architecture. Do not claim Ladder Network implementation until it is added and tested. Included demo telemetry is synthetic, not real industrial data or proof of industrial performance. Results are generated by running the experiment; no metrics are fabricated in advance.

## Windows setup
1. Install Python 3.10 or newer.
2. Extract the ZIP and open terminal in this folder.
3. `python -m venv .venv`
4. `.venv\\Scripts\\activate`
5. `pip install -r requirements.txt`
6. `python app.py`
7. Open `http://127.0.0.1:5000`, create an account, then sign in.

CSV columns: numeric sensor features plus `fault_label`. Keep test set independent; test labels must not be used in training or pseudo-label generation.
